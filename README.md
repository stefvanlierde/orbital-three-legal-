# Orbital Three — Privacy & Support

Public bilingual privacy-policy site for **Orbital Three**, an independent original Wear OS watch face.

- **Dutch:** [Privacybeleid](https://stefvanlierde.github.io/orbital-three-legal-/index.html#nederlands)
- **English:** [Privacy Policy](https://stefvanlierde.github.io/orbital-three-legal-/index.html#english)
- **Support:** [Stef.van.lierde@gmail.com](mailto:Stef.van.lierde@gmail.com)
- **App package:** `be.orbitalthree.watchface`

The site is a single self-contained [`index.html`](index.html) with no third-party tracking or external website assets.

## Publishing

The repository is public. In **Settings → Pages → Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then **Save**.

Once published and verified publicly, use this privacy policy URL in Google Play Console:

`https://stefvanlierde.github.io/orbital-three-legal-/index.html`

**Security:** This legal repository must never contain the watchface source code, private signing keys, uploaded Play bundles, or developer credentials.

**Independence:** Orbital Three is an original project and is not affiliated with Ressence, Samsung, or Google.
